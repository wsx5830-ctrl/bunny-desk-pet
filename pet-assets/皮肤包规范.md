# 桌宠皮肤包交付规范 v1

> 主皮肤已接入：`skins/default`（兔耳小人）。皮肤系统已可运行：打开 `pet-demo-skins.html`，
> 右键桌宠 / 按 S / 点任务栏"换装"打开皮肤柜，数字键 1-9 快速切换，选择会记住（localStorage）。

## 一、你要给我什么

**每套皮肤一张图即可**，其余全部由工具链完成。图片要求按优先级：

| 项目 | 要求 | 说明 |
|---|---|---|
| 格式 | PNG 透明底最佳；JPG/PNG 白底也行 | 白底我自动抠（只从边缘抠，衣服内部白色不受影响） |
| 尺寸 | ≥1024×1024 | 我会归一化到 640×640 标准画布 |
| 姿势 | 正面、直立、四肢可见 | **姿势越接近主皮肤，自动拆层成功率越高** |
| 画风 | 黑色描边闭合的 Q 版线稿平涂最稳 | 厚涂/无描边画风需要人工干预拆层 |
| 构图 | 角色完整、不要裁切、画面里只有角色 | 不要背景、水印、文字、分格 |

## 二、每套皮肤可选附加信息

发图时顺带告诉我（不给就用默认值）：

- **名字**：显示在皮肤柜里（如"新春红""学士服"）
- **主色**：换装时任务栏圆点和"换装"按钮的点缀色，`#RRGGBB`
- **专属台词**（可选）：按状态给几条，如 poke 状态 4-8 条；不给则沿用通用台词

## 三、系统怎么工作（不需要你操心，但值得知道）

```
你的图 ──► ingest_skin.py ──► skins/<id>/
          抠底 → 拆层 → 归一化      ├─ layers/*.png   (640×640, 12 层槽位)
                                    ├─ thumb.png      (皮肤柜缩略图)
                                    └─ skin.json      (层清单 + 支点 + 主色 + 台词)
                              ──► build_skins.py ──► 注入 pet-demo-skins.html
```

- **标准画布**：640×640，角色统一身高 560px、脚底贴 y=616、身体中线 x=320。
  这保证换皮时角色不会突然变大变小、不会悬空或陷地。
- **12 个层槽位**：`tail, shorts, body, hand_L, hand_R, face, mouth, eye_L, eye_R, hair, ear_L, ear_R, hat`。
  图里没有的部件（尾巴、帽子）自动跳过，对应动画（尾巴摆、帽子扇）自动降级，**不会报错也不会穿帮**。
- **必需 5 层**：face / body / hair / eye_L / eye_R。缺了任何一层，皮肤包会被判为无效并跳过。
- **支点自动计算**：耳朵绕根部摆、头绕脖子点、眼绕中心眨。接入后我会渲染旋转验证图确认。
- **换皮动画**：模糊淡出 → 换层 → 淡入 + Q 弹一下 + 台词"换好啦！"。

## 三·二、台词怎么写

台词只有一个真源：`台词表.csv`（83 条）。列含义：

| 列 | 说明 |
|---|---|
| `skin` | **留空 = 通用台词**，所有皮肤共用；填皮肤 id（如 `yigong`）= 该套专属台词，出现权重是通用的 2 倍 |
| `state` | `idle` / `poke` / `drag` / `fall` / `sleep` / `wake` |
| `text` | 台词正文，**不要写英文逗号**（会破坏 CSV），需要停顿用空格或中文逗号 |
| `weight` / `cooldown_seconds` | 权重与冷却，当前页面按随机抽取，这两列留给后续接入真实调度 |

改完台词跑 `python tools/build_skins.py`，会重新注入页面与每套皮肤的专属池，无需改代码。

## 三·五、动画能力表（每套皮肤可以不一样）

`skin.json` 里的 `anim` 决定这套皮肤哪些部件会自己动。默认值按"有该层就能动"推断，接入时可显式指定：

| 字段 | 默认 | 关闭后的效果 |
|---|---|---|
| `breathe` | 开 | 身体不再呼吸起伏 |
| `blink` | 开 | **不眨眼**（一般不要关） |
| `nod` | 开 | 被戳时不点头 |
| `hairSway` | 开 | 头发不自己轻晃 |
| `earSway` | 有耳层则开 | 耳朵不被独立摆动/扇动，**但仍归入头部组，随点头一起转** |
| `tailSway` | 有尾层则开 | 尾巴不摆 |

**什么时候该关 `earSway`**：耳朵本身就是造型的一部分——兽耳长在头上、发箍上的假耳、
帽子上的装饰耳。这类耳朵跟着头动是合理的，自己独立晃就是穿帮（会和头发生相对位移）。
主皮肤的兔耳之所以摆动，是因为它是独立发箍、物理上确实会晃。

关掉后仍然保留：**眨眼、呼吸、点头、拖拽甩动、落地回弹、久坐入睡、台词气泡**。
接入时加 `--static-ears` 参数即可，皮肤柜里会标注"耳朵固定"。

示例命令：

```bash
python tools/ingest_skin.py 新皮肤.png cat_school "学士猫" --accent "#3A6EA5" --static-ears
python tools/build_skins.py
```

## 四、已知边界（提前说清楚）

1. **换色 ≠ 换装**。现有的 berry/mint/caramel 三个皮肤是主皮肤的色相偏移，仅用于验证切换机制，
   连嘴巴腮红都会跟着变色，属正常。你发来的才是真换装。
2. **姿势差异大时拆层需人工校准**。若某套皮肤是侧身/抱臂/坐姿，自动切层可能把部件粘连，
   我会先跑再人工修，最坏情况该皮肤退化为"单图 + 眨眼贴层"。
3. **被遮挡区域仍然没有像素**。和主皮肤同理：耳朵根部、袖子里的手臂等区域若要做大角度
   动画需画师补画；小幅动画（现在全部如此）不受影响。
4. **最多建议 12 套常驻**。皮肤柜是横向网格，超过会滚动；无所谓上限，但列表太长切换体验差。

## 五、发图后的流程

1. 你发图 + 名字（+ 主色/台词，可选）
2. 我跑 `ingest_skin.py`，渲染合成验证图 + 旋转测试图给你确认
3. 跑 `build_skins.py` 刷新皮肤柜
4. 全部接入后，把 `pet-assets/` 打包即是完整素材包
