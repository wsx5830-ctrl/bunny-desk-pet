# 桌宠素材交付规格 —— 爆炸头 Q 版小男孩（红外套·右手火焰）

## 角色特征判定

- 1:1 头身比 Q 版，四肢短且结构简单 → 骨骼数量少，Spine / Live2D 都好做
- 蓬松爆炸头，软团状 → 最适合做摆动物理（Live2D 摆锤 / Spine 物理），是"活着感"的最大来源
- 眼睛占脸 1/3 → 表情差分空间大，眼嘴拆层收益高
- 软笔刷厚涂画风，边缘柔和 → 拆层后接缝处需要留出血，否则转头露白边
- 右手持火焰 → 火焰必须独立成层（2–4 帧循环），不要画死在手里

## 路线判定

| 条件 | 路线 |
|---|---|
| 能拿到画师分层源文件（PSD / Procreate 分层导出） | Live2D，见《分层清单_Live2D.md》 |
| 只有这张成品图，找不到源文件 | 序列帧（画师按状态逐帧重画）或 V0 单图方案 |
| 想先跑通流程验证手感 | V0 单图方案，今天就能上 |

无论哪条路，先向画师要一张 **2048×2048 以上 PNG 透明底定稿图**作为抠图基准。
注意：当前图是 JPG 白底且带画师水印（@LLZXXXLY），直接抠会有白边和残留水印，商用前需取得授权与无水印源文件。

## 通用规格（两条路线都适用）

- 画布 512×512（源文件 1024 以上），PNG-24 带 Alpha，**一律不要 JPG**
- 所有帧同一画布，不裁剪、不缩放
- 锚点：角色脚底对齐画布底边中心（约 256, 500），每帧位置严格一致
- 不预烘焙阴影、对话框、背景、光晕
- 水印与签名不得出现在任何交付帧内
- 命名 `idle_01.png`、`idle_02.png`，从 01 起编号，放入对应 sprites 子目录

## V0 立即可用方案（不等画师）

1. 现有图抠白底 → `sprites/idle/idle_01.png`
2. 火焰单独抠出 2 帧 → `flame/`，idle 时叠在右手位置循环
3. 代码侧：CSS 呼吸缩放（周期 2.5s）+ 点击弹跳 + 拖拽跟随
4. 局限：不会转头、没有表情变化，属于占位验证

## 验收清单

- [ ] 六状态齐全（V0 只需 idle + poke + drag）
- [ ] 循环状态首尾帧无缝衔接
- [ ] 单次状态结尾姿势 = idle 第一帧姿势
- [ ] 脚底锚点全部对齐，连播不抖动
- [ ] 缩到 128px 仍能认出角色
- [ ] 台词表、音效、参数表齐全
